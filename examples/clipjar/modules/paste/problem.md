# Paste

Finding a clip is half the job. If choosing it only copies it back, the user must still return to the right app and paste, the very detour the picker avoids.

Paste injection lands the clip in the app the user was using. The macOS price is a permission: sending key presses for the user needs Accessibility, which also lets an app watch and control other apps, so the user must be told honestly why it is asked for.

Without it the tool works, but every use ends with a manual paste.
