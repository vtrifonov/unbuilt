## Note list window

<!-- One section per screen or surface (FORMAT.md §3). -->

- **Purpose**: show past notes, newest first.
- **Key elements**: a scrolling list, one row per note with its time and first line.
- **States**: empty shows a hint to press the capture key; loading shows a spinner; error shows a message with a retry button.
